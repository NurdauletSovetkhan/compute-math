# Unified Main Program для Week-1

## Описание

`unified_main.py` - это единый главный файл, который заменяет все отдельные `main.py` файлы в различных assignment. 

Он предоставляет удобное меню для запуска любого задания из week-1.

## Особенности

✅ **Все задания в одном месте** - не нужно запускать каждый main.py отдельно  
✅ **Динамическая загрузка модулей** - правильная работа импортов для каждого задания  
✅ **Удобное меню** - простой выбор нужного задания  
✅ **Сохранение контекста** - корректная работа относительных путей и импортов  

## Доступные задания

### 1. Assignment 1 - Решение нелинейных уравнений
- Метод бисекции (Bisection)
- Метод неподвижной точки (Fixed Point)
- Метод Ньютона-Рафсона (Newton-Raphson)
- Метод секущих (Secant)
- Метод ложного положения (False Position)

### 2. Assignment 2 - Системы линейных уравнений
**Прямые методы:**
- Правило Крамера (Cramer's Rule)
- Метод Гаусса (Gaussian Elimination)
- Метод Гаусса-Жордана (Gauss-Jordan)

**Итерационные методы:**
- Метод Якоби (Jacobi)
- Метод Гаусса-Зейделя (Gauss-Seidel)
- Метод последовательной верхней релаксации (SOR)

### 3. Assignment 3 - Аппроксимация кривых
- Прямая линия (Straight Line)
- Квадратичная функция (Quadratic)
- Кубическая функция (Cubic)
- Экспоненциальная функция (Exponential)
- Логарифмическая функция (Logarithmic)
- Степенная функция (Power)

### 4. Assignment 4.1 - Конечные разности
- Прямые разности (Forward Differences)
- Обратные разности (Backward Differences)
- Сравнение методов

### 5. Assignment 4.2 - Интерполяция
- Интерполяция Лагранжа (Lagrange)
- Прямая формула Ньютона (Newton Forward)
- Обратная формула Ньютона (Newton Backward)
- Автоматический выбор метода

### 6. Assignment 5.1 - Численное дифференцирование
- Дифференцирование с равномерным шагом (Equally Spaced)
- Дифференцирование с неравномерным шагом (Unequally Spaced)
- Анализ экстремумов (Extrema Analysis)

### 7. Assignment 5.2 - Численное интегрирование
- Метод трапеций (Trapezoidal Rule)
- Метод Симпсона 1/3 (Simpson's 1/3 Rule)
- Метод Симпсона 3/8 (Simpson's 3/8 Rule)
- Сравнение методов

## Использование

### Запуск программы

```bash
python unified_main.py
```

или

```bash
python week-1/unified_main.py
```

### Навигация в меню

1. После запуска вы увидите главное меню со всеми доступными заданиями
2. Введите номер задания (1-7) для запуска
3. Введите 0 для выхода из программы
4. После завершения задания нажмите Enter для возврата в главное меню

## Технические детали

### Структура файла

```
unified_main.py
├── Импорты и инициализация
├── print_main_menu() - отображение главного меню
├── load_and_run_main() - динамическая загрузка модулей
├── run_assignment_X() - функции запуска каждого задания
└── main() - главная функция программы
```

### Как это работает

1. **Динамическая загрузка модулей**: Используется `importlib.util` для динамической загрузки каждого `main.py` файла
2. **Изменение рабочей директории**: Перед запуском каждого задания программа переходит в соответствующую директорию
3. **Управление путями**: Добавление директории модуля в `sys.path` для корректной работы импортов
4. **Изоляция модулей**: Каждый модуль загружается с уникальным именем для избежания конфликтов

### Преимущества перед отдельными main.py

- ✅ Не нужно помнить, где находится каждый main.py
- ✅ Единая точка входа для всех заданий
- ✅ Легко добавить новые задания
- ✅ Сохранение всех функциональностей оригинальных main.py
- ✅ Корректная работа относительных импортов

## Решение проблем

### Ошибка импорта модуля

Если вы видите ошибку "Не удалось загрузить Assignment X":
- Проверьте, что файл `main.py` существует в соответствующей директории
- Убедитесь, что все необходимые модули установлены

### Ошибки при выполнении задания

Если задание выполняется с ошибками:
- Попробуйте запустить оригинальный `main.py` напрямую
- Проверьте, что все зависимости установлены
- Убедитесь, что данные в примерах корректны

### Проблемы с путями

Программа автоматически управляет путями, но если возникают проблемы:
- Убедитесь, что вы запускаете `unified_main.py` из корня week-1 или выше
- Проверьте структуру директорий
